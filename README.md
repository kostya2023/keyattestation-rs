# keyattestation-rs

Android Key Attestation library for Rust.

## Features

- Parse Android Key Attestation ASN.1 structures
- Verify X.509 certificate chains
- Convert ASN.1 structures into Rust models

## Status

⚠️ This project is under active development. The public API may change.
